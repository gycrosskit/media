## 本地行为检查

以下命令从仓库根目录执行。配置`ANDROID_HOME`与可运行Gradle的JDK；Kotlin/Native测试需要macOS、Xcode及iOS Simulator运行环境。Node测试转译真实ArkTS源码并使用受控SDK替身，`TYPESCRIPT_PATH`可指定已有TypeScript模块。

```sh
bash gradlew :media-core:testDebugUnitTest :media-core:iosSimulatorArm64Test --max-workers=1
bash gradlew -p verification-kuikly test --max-workers=1
node --test ohos/media/test/media.test.cjs
# 需要已启动的Simulator；此项实际运行UIKit转场fixture。
bash scripts/verify-ios-picker.sh
```

只运行受影响目标；需要确认本轮真实执行时加`--rerun-tasks`，不要把`UP-TO-DATE`算成新执行。平台测试结果XML位于`media-core/build/test-results/`；独立Module测试结果在`verification-kuikly/build/test-results/test/`。这些测试不调用真实分享、认证、拨号或定位业务。

## 原生产物与独立消费

HarmonyOS工具链需要DevEco SDK、ohpm与hvigorw。在`ohos/`目录执行：

```sh
ohpm install --all
hvigorw --mode module -p module=MediaNative@default -p product=default assembleHar --no-daemon
```

安装与公开API消费工程按[接入指南](接入指南.md)和[README](../README.md)执行；`scripts/verify.sh`是更广的维护检查，不是每次小改动的必跑全套。构建/本地HAR消费不等于OHPM Registry或本版远程消费。Maven、Swift/Pod与HAR按各自版本验证。

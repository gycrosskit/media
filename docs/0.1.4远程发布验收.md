## Kuikly 原厂仓库选择

合并远程消费者曾从 Eazy 取得 Kuikly `core-render-android:2.28.0-2.0.21-ohos` 的 POM/module，随后同源 AAR HEAD 返回 404；Gradle 失败列表只搜索该已选仓库。实际 HTTP 复查时，Eazy 与腾讯 `maven-tencent` 的 POM/module/AAR GET 均为 200，之后 AAR HEAD 也均为 200；实际文件均为 934067 字节，SHA-256 `f1108225d64b225e53190a088516511c2eee359bbae2de0725eda27f4a9f7dc3`，四种声明哈希匹配。已证当次仓库选择与响应故障，不能将当前完整文件判为永久缺失；先 404 后 200 的服务器原因未取得证据。

安装配置只将 `com.tencent.kuikly-open` 通过 `exclusiveContent` 固定到 `https://mirrors.tencent.com/nexus/repository/maven-tencent/`，避免镜像返回 metadata 后无法为缺失产物切源。Maven 版本、Swift/HAR 配套、其他 SDK 与插件仓库不改。证据保存在消费者忽略目录 `diagnose/kuikly-renderer-repository/`。

# media 0.1.4 远程发布验收

本轮只更新 Maven core/Kuikly。Swift Package 保持 0.1.2，HAR 保持 0.1.3，原生源码和桥契约未变。

## 修复与本地验证

Android/iOS Picker 的请求、回调、取消 owner 与释放清理在 Main 串行；dispose 立即撤销旧结果交付且保留之后的新请求。保存权限/Photos bridge 入口切 Main，业务消费恢复调用方 dispatcher。

Android 5 项、iOS Simulator 实际执行 6 项，0 失败、0 跳过；取消和迟回调覆盖真实后台 worker。Android Debug、iOS device arm64 编译通过。日志位于忽略目录 build/thread-boundary-*.log。

## 发布门禁

新 staging、完整 Maven 归档校验、不可变标签、Release 下载 SHA、JitPack 精确模块审计及 Android/iOS/OHOS 远程消费待执行。真实设备相机、权限、选择器与相册写入由宿主验收。

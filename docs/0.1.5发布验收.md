# media 0.1.5 发布验收

2026-10-05，Maven/HAR `0.1.5` 与独立 Swift source revision `native-0.1.3` 为本轮候选；网络发布与远程消费记录在实际完成后补充，不用历史版本的结果代替。

## 修复与源码覆盖

现代 Android Picker 的注册/启动失败走统一请求清理；相机临时文件按既有 suffix 隔离；maxCount 公共合同统一为1..500。保存仍写原字节，Android API28+ 用 ImageDecoder 拒绝 partial，API24–27、Swift/HAR 对 PNG/JPEG/WebP 核对结束边界后做小尺寸实际解码。JPEG 按段长度跳过APP/metadata，避免内嵌缩略图 EOI 冒充主图结束；保留合法尾随数据。兼容校验不声明完整编码/CRC验证，系统容忍其他部分图像的限制保持真实记录。

完整覆盖21个自有生产 Kotlin/Swift/ArkTS/桥/manifest和9个配置，文件清单、公开调用链、最低系统、线程/取消、格式依据与限制见[完整源码审查](完整源码审查.md)。Android API24+，iOS14+，HAR target/compatible API22不变。KMP iOS桥调用同一Swift saveImage校验入口。

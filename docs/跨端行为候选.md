# 0.1.6 跨端行为候选（未发布）

`dispose` 在三端均为终态，幂等取消待请求与迟到结果；随后 pick 返回 Failed(媒体宿主已释放)，重用须创建新实例。真实生产调用方在 Activity/runtime destroy 时释放；未发现销毁后复用，公共方法签名保留。系统取消、权限拒绝/阻止/限制保持不同结果。

`ImageContentPolicy` 约定一次选择的原始编码和输出编码分别合计不超过 32 MiB，单次保存同限额；无压缩保留原始编码，显式压缩输出 JPEG 并同步 MIME/扩展名。超限选择返回 Failed(limitExceededMessage)，超限保存使用既有 INVALID_CONTENT，发生在授权/写入之前。保留现有公开枚举以兼容宿主 exhaustive when。

PNG/JPEG 是公共基线。Android 现用系统 MIME/真实采样解码支持 GIF/BMP/HEIF 等扩展，不再手写三格式白名单；iOS ImageIO、OHOS ImageKit 的其他已支持格式继续保留。具体格式仍受 OS 解码能力限制，不可解码/不支持保存返回 INVALID_CONTENT，不触发写入。32 MiB 限制编码数据，不等于运行时内存峰值；系统 SDK 回传 NSData/Data 前的内存由系统管理。

iOS JPEG 输出超限以 ImageSelectionError.tooLarge 传回 camera/gallery，再将整次请求失败；不会将超限当成可跳过的 nil。Swift 模拟器用64-byte内部预算执行真实 UIKit JPEG 编码并验证 typed 原因；合法 PNG 伴图分别验证，整批 caller 失败由生产 catch/终态分支静态证明，非真实 PHPicker 同批回调验收。

历史发布记录（不含本次修复）：Maven 0.1.7；Swift native-0.1.3 / HAR 0.1.6沿用原字节。源码基线：`d217f7163af7f91e69ab4abc6a4f023b3d267b95`，叠加本次修复；最终源码由不可变Git标签`0.1.7`定位。构建、checksum及各渠道实际验收结果见[版本发布记录](https://github.com/gycrosskit/media/releases/tag/0.1.7)，源码/替身测试范围见本页验证表；不声明真实设备业务验收通过。

## 产物与职责

| 模块/产品 | 实际职责 |
|---|---|
| `media-core` | KMP ImagePickerPlatform / ImageSavePlatform、Android 实现及 iOS bridge；无内置业务 UI。 |
| `media-kuikly` | 仅 ohosArm64 的 MediaModule，实现上述接口，发送 JSON/Base64 到 GycMedia；不是三端 UI 模块。 |
| `GycMedia` | Swift Package 产品，MediaClient 调用 PhotosUI/UIKit/Photos；KMP 需要宿主接 IosMediaSdkBridge。 |
| `@gycrosskit/media` | API22 HAR，原生 MediaModule，cameraPicker / photoAccessHelper / ImageKit；无独立 ArkTS picker facade。 |

构建边界：[core构建](../media-core/build.gradle.kts)、[Kuikly构建](../media-kuikly/build.gradle.kts)、[模块清单](../settings.gradle.kts)、[OHOS SDK配置](../ohos/build-profile.json5)。

除上表明确的 UI 入口外，本库没有独立 CMP 页面模块。Android/iOS 可由宿主原生适配把同一能力供 CMP 与 Kuikly 使用；“可注入两套UI”不代表库自动完成宿主接线、同名 Renderer 注册或品牌验收。

## 公开 API 组

- `ImagePickerPlatform.pick(ImagePickerRequest)` / `dispose()`：GALLERY/CAMERA、maxCount与可选ImageCompression，返回Selected/Cancelled/PermissionDenied/PermissionBlocked/PermissionRestricted/Failed等公开终态。
- `ImageSavePlatform.save(ImageSaveRequest)`：编码字节与fileNamePrefix，返回ImageSaveResult；格式和权限由平台实现检查。
- OHOS `MediaModule` 同时实现picker/saver；JSON传输不是单独业务上传API。

## API 合同与差异分类

| 分类 | 具体输入 / OS / SDK边界 | 调用方应如何处理 |
|---|---|---|
| 厂商限制 | 选图数量1..500，默认1；camera只一张，系统Picker可以进一步限制。 | 三端都校验合同，不承诺每种设备可选择500张；宿主决定取消/拒绝/失败文案。 |
| 厂商限制 | compression=null保持可取得的原始编码；iOS系统相机仅返回UIImage时会编码JPEG。 | 不能把相机UIImage重编码称为原始文件字节；图像方向按原生输入纠正。 |
| 组件边界 | 单次输入原图总量、输出结果总量分别不超过32MiB；maxDimension>0、jpegQuality1..100。 | OHOS Base64先限长再decode，源文件读取也前置限额；大小上限不等于大图峰值内存验收。 |
| 厂商限制 | OHOS取消不能强制关闭系统Picker。 | 本地请求结束后，原生Picker返回前仍busy；Android/iOS替换请求分别清理旧owner，旧cancel不能影响新请求；dispose为终态，继续使用须新建Picker/Module。 |
| 宿主职责 | Android API24+；API28及以下保存需要WRITE_EXTERNAL_STORAGE；iOS14+需相机/相册addOnly用途声明；OHOS目标/兼容API22。 | 提供权限入口、当前页面/bridge、资源生命周期，上传/业务限制归宿主。 |
| 未验收 | 真实相机/相册写入、多品牌安装包、远程新候选。 | 本轮源码/mock/Simulator证据不能替代权限UI、硬件或远程制品消费。 |

Maven 0.1.8 修复：Android 仅在 MediaStore 行成功解除 pending（更新一行）后返回 SAVED，失败删除临时行。iOS PHPicker 每次只读取一个临时文件，读取前及流读取过程中执行累计 32 MiB 原始字节预算；输出另计 32 MiB。取消/替换不再启动后继 provider，终态异步交付以支持回调重入。原图和 JPEG 的 displayName 都取 basename；这是跨平台元数据一致性，不表示宿主可以无校验地用它拼接路径。
